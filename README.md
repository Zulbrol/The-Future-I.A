# The Future IA

> **The Future IA** é um ecossistema de Engenharia de Software baseado em Inteligência Artificial, desenvolvido para funcionar localmente e coordenar múltiplos agentes especializados capazes de projetar, pesquisar, desenvolver, revisar, testar e documentar aplicações completas.

O objetivo do projeto é criar um sistema de IA que atue como uma equipe de engenharia de software, automatizando desde a análise inicial de requisitos até a entrega final do projeto.

---

# Objetivos

* Executar modelos de IA localmente.
* Coordenar múltiplos agentes especializados.
* Automatizar o desenvolvimento de software.
* Criar projetos completos de forma organizada.
* Gerenciar tarefas entre agentes.
* Construir memória de longo prazo.
* Integrar ferramentas de desenvolvimento modernas.

# Como executar

Clone o projeto:

```bash
git clone https://github.com/Zulbrol/The-Future-I.A.git
```

Instale as dependências:

```bash
pip install -r requirements.txt
```

Configure o arquivo `.env`.

Execute:

```bash
python main.py
```
